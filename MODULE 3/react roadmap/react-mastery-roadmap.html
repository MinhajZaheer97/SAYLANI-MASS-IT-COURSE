Phase 8 — Final Project (Weeks 21–24)

🏆 Final Project — "ShelfSpace" Personal Library & Reading Tracker

A portfolio-quality app: browse books via a free public API (e.g., Open Library), manage a personal shelf, track reading progress, notes, and stats.

  • Objective: One large production-grade React app using only roadmap concepts (+ minimal React Router for Home / Details / My Shelf / Not Found).
  • Features: Debounced API search, book details view, shelf CRUD with useReducer + Context, reading progress + optimistic updates (useOptimistic), notes with React 19 form Actions, stats dashboard, dark/light theme, portal modals, error boundaries, lazy-loaded routes, localStorage persistence, responsive UI, keyboard-accessible modals/forms, RTL component tests.
  • Folder Structure: feature-based — src/features/search/, src/features/shelf/, src/features/stats/, plus shared src/components/, src/hooks/, src/context/, src/utils/, src/constants/, src/__tests__/
  • Skills Practiced: Everything — component architecture, all hooks, custom hooks, Context + useReducer, React 19 features, performance optimization, a11y, testing.
  • Best Practices: Feature isolation, profiled performance, documented custom hooks, meaningful commit history.
  • GitHub Milestone: v1.0-shelfspace — deployed to Vercel/Netlify, live link in README, screenshots, test badge.
